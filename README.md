# Stotra Sadhana

Local-first stotra and sahasranama learning platform with spaced repetition.

Initial content: Sri Tara Sahasranama.

## Features

- Select one or more texts to focus on
- Mixed review across selected texts
- Pravaha and Samuha navigation
- Local progress stored in the browser
- Again / Hard / Good / Easy SRS ratings
- Static, framework-free web app

## Run locally

```bash
python3 -m http.server 8080
```

Open `http://localhost:8080`.
